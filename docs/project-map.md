## Дальше

1. Поднять стенд, прогнать `pnpm b24:setup`, отметить методы ✅ в `docs/REST_METHODS.md`.
2. Владельцу: защита `main` и прочее по `docs/REPO_SETUP_CHECKLIST.md`.
3. Выкатить стенд `wsp.algena.by` с `ONEC_TOKEN` и передать программисту 1С `docs/onec-contract.md`.
4. Этап 2 — Битрикс24 и доступ.
