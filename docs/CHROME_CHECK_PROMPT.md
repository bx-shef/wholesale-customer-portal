# Проверка ЛК в браузере: промпт для Claude в Chrome

> Last reviewed: 2026-10-21

Промпт для расширения Claude в Chrome: пройти кабинет глазами клиента и сотрудника и вернуть
отчёт. Перед запуском:

1. Сервер обновлён (`make prod-redeploy`), `make health` показывает коммит из `main`.
2. В Chrome вы вошли: в коробку `https://crm.algena.by` — под сотрудником; ключ тестового клиента
   ЛК выдан во вкладке «Личный кабинет» карточки тестовой компании.
3. Под рукой: телефон или email и ключ тестового клиента, логин и пароль стенда 1С
   (`ONEC_TEST_LOGIN`/`ONEC_TEST_PASSWORD`). Вписываете их сами, когда Claude попросит, — в
   промпт не вставляйте.

Скопируйте блок ниже целиком.

---

```text
Ты проверяешь личный кабинет оптового покупателя https://wsp.algena.by (Nuxt, интерфейс Bitrix24 UI)
и его приложение в коробке Битрикс24 https://crm.algena.by. Работай в новой вкладке. Ничего не
покупай и не подтверждай по-настоящему: заявку отправляй только одну и только с комментарием
«ТЕСТ ЛК, не исполнять». Пароли и ключи не вводи сам — когда нужен вход, остановись и попроси меня
ввести их. Ничего не удаляй, не меняй настройки портала и сотрудников.

Для каждого пункта запиши: что сделал, что увидел (коротко), ✅ или ❌, для ❌ — скриншот и текст
ошибки со страницы или из консоли (DevTools → Console, ошибки красным). Проверь каждый пункт на
ширине окна телефона (DevTools → Toggle device toolbar, 390×844) и на обычной ширине.

1. Вход. Открой https://wsp.algena.by — должно перенаправить на /login. Попроси меня ввести телефон
   или email и ключ. После входа — каталог. Проверь: неверный ключ даёт один и тот же текст отказа.
2. Каталог (/). Список товаров с ценами, поиск по слову из названия и по артикулу, фильтры в
   шторке (раздел, бренд, «в наличии»), сортировка, подгрузка при прокрутке, «Показать ещё».
   Состояние фильтров — в адресной строке (обнови страницу — фильтры остались).
3. Карточка товара (/product/…). Цена с НДС, кратность и минимум, остатки, свойства, аналоги,
   «В корзину». Кнопка «Обсудить с ИИ».
4. ИИ-помощник (панель справа или на весь экран на телефоне). Спроси: «Найди клей для плитки»,
   затем «Покажи аналоги в наличии» и «Сравни первые два». Проверь: карточки с ценой и кнопкой
   «В корзину», шаги «Ищу…», «Ищу аналоги», «Сравниваю товары», цены в тексте совпадают с карточками.
   Поставь 👍 или 👎 ответу.
5. Корзина (/cart). Добавь 2–3 товара, измени количество (кратность соблюдается), выбери адрес
   доставки, посмотри дату доставки («Машина приедет …» или «дату согласует менеджер»), итог.
   Отправь ОДНУ заявку с комментарием «ТЕСТ ЛК, не исполнять». Повторный клик не создаёт вторую.
6. Мои заявки (/orders). Отправленная заявка видна со статусом.
7. Профиль (/profile). Компания, договор, менеджер, «Позвонить» / «Заказать звонок» (не нажимай
   «Заказать звонок» больше одного раза).
8. Справка (/help). Открывается, есть раздел «Кабинет на телефоне и без сети».
9. Без сети. В DevTools → Network поставь Offline. Обнови главную: сверху плашка «Нет сети: открыто
   сохранённое ранее…», открытые раньше каталог и карточка видны. Корзина и «Мои заявки» без сети
   не открываются или говорят об ошибке — это ожидаемо. Нажми «Выйти» без сети: должно появиться
   «Выйти не удалось: нет связи с сервером», выхода не происходит. Верни Online.
10. Выход. Нажми «Выйти» с сетью → /login. В DevTools → Application → Cache Storage не должно
    остаться кэшей `lk-data-…`; в Application → Service Workers воркер снят. Войди снова — воркер
    вернулся (`/sw.js`). Application → Manifest: имя «Личный кабинет оптового покупателя», иконки 192
    и 512 без ошибок; браузер предлагает «Установить приложение».
11. «Состояние системы»: https://wsp.algena.by/api/system — попроси меня ввести логин и пароль
    стенда. Источник 1С (мок / настоящая / по OData), потоки обмена со статусами, ошибок нет или они
    понятны. Не нажимай «Запустить» без моего разрешения.
12. Стенд 1С: https://wsp.algena.by/api/onec-test (тот же вход). Режимы «OData 1С — каталог»,
    «OData 1С — цены и остатки», «OData 1С — клиенты и соглашения». Адрес и доступ к OData вписываю я.
    Для каждого режима: дождись результата (идёт до нескольких минут), нажми «Скопировать отчёт» и
    вставь отчёт в свой ответ целиком. В «клиенты и соглашения» должна быть строка «Тестовый заказ
    без записи (§1.7)».
13. Коробка. В https://crm.algena.by открой приложение ЛК (меню слева) — вкладка «Ближайшие
    доставки». Открой карточку тестовой компании → вкладка «Личный кабинет»: контакты, статусы
    доступа, кнопки выдачи и отзыва ключа (не нажимай). Найди сделку тестовой заявки в воронке
    «Заявки ЛК»: товары, сумма, комментарий.

В конце дай сводку: таблица «пункт — ✅/❌ — коротко что не так», затем список ❌ по важности
(сломано для клиента / неудобно / косметика) и отчёты стенда из пункта 12. Ничего не исправляй.
```
